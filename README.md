# workforce-app · 인력관리 (실시간 DB)

인력·거래처·근무/입금·문자·관리자 메신저를 한 화면에서 관리하는 모바일 웹 앱입니다.
화면 주소: https://heepro77.github.io/workforce-app/

## 구성
- 단일 파일 `index.html` (빌드 도구 없음, GitHub Pages로 서빙)
- 데이터: Supabase 실시간 DB (`wf_workers` · `wf_clients` · `wf_logs` · `wf_sms` · `wf_messages` · `wf_expenses` · `wf_admins`)
  - `postgres_changes` 구독으로 관리자 3명 화면에 즉시 반영
  - DB·테이블이 없거나 오프라인이면 자동으로 이 기기(localStorage)에 저장하고 상단 칩에 상태 표시
    (`🟢 실시간 연결됨` / `🟡 DB 테이블 대기중` / `🔴 오프라인 · 로컬`)
- 관리자 이름은 공개 페이지라 기본값이 `관리자 1 (대표)` · `관리자 2 (현장)` · `관리자 3 (정산)`으로 익명 처리되며, 설정에서 이름과 비밀번호를 바꿀 수 있습니다(로그인해야 들어옵니다).
- 로그인 비밀번호는 **SHA-256 해시**로만 저장합니다(처음 값 `1234`). `wf_admins` 표가 없으면 이 기기에만 저장하고 설정에 SQL 안내를 띄웁니다.
- 실제 문자(SMS)는 발송되지 않고 발송 이력만 기록합니다.

## 관리자 로그인 · 비밀번호 · 기록 작성자 (2026-11-24 추가)
- **로그인 화면**: 앱에 들어가면 관리자 3명 중 한 명을 고르고 비밀번호를 넣어야 데이터가 보입니다. 로그인하면 `localStorage`(`wfp_session`)에 세션이 남아 새로고침해도 유지됩니다.
- **초기 비밀번호는 `1234`** (a1 · a2 · a3 모두). 설정 → **관리자 이름 · 비밀번호**에서 관리자별로 이름·역할과 새 비밀번호(4자리 이상, 확인 입력)를 바꿉니다. 비밀번호는 SHA-256 해시(`pass_hash`)로만 저장합니다.
- **로그아웃 · 전환**: 오른쪽 위 관리자 칩을 누르면 전환 창(전환할 관리자의 비밀번호 필요)과 로그아웃이, 설정 아래에도 로그아웃이 있습니다. 전환·로그아웃하면 그 뒤 기록은 바뀐 관리자 이름으로 남습니다.
- **기기 간 동기화**: `wf_admins`(이름·역할·`pass_hash`·`updated_by`·`updated_at`)로 관리자 3명 기기의 이름·비밀번호를 맞춥니다. 표가 없으면 로그인·비밀번호 변경은 이 기기에서 그대로 동작하고 설정에 `wf_admins 표가 아직 없습니다` 안내와 SQL 열기가 뜹니다.
- **기록 작성자 표시**: 근무 등록·오늘 출역 ON/OFF(1차·2차 줄)·지출 등록·문자 발송에 `created_by`(수정 시 `updated_by`)를 저장하고, 기록 카드·오늘 출역 줄·📒 장부(거래처/인력/지출)·문자 내역에 **`기록: 관리자 이름`** 배지(여러 명이 만든 묶음은 `기록: 관리자 1 외 1명`, 수정한 건은 `수정: 관리자 2`)를 표시합니다. 문자 발송 기록은 `wf_sms.sent_by` 에 관리자 id로 남습니다.

## 화면 기능 (2026-11-24 갱신)
- **오늘 출역 체크**: 인력별 `ON`(초록) / `OFF`(회색) 스위치.
  - `OFF → ON`: 바로 켜지지 않고 **확인창**(`{이름} 지금 시각(HH:MM)으로 출역 ON 할까요?` — 확인/취소)이 뜹니다. **확인을 누른 순간의 현재 시각**(HH:MM + ISO 타임스탬프)이 시작 시간으로 기록되고 ON 으로 바뀌고, **취소하면 아무것도 바뀌지 않습니다**. 하루에 몇 번이든 반복 가능.
  - `ON → OFF`: **누른 순간의 현재 시각이 종료 시간으로 기록**되고 OFF 로 돌아갑니다. 기록은 삭제되지 않고, 시간 × 시급으로 일당이 자동 계산됩니다.
  - 인력 줄 아래에 그날 완료된 건이 `1차 ON 06:00 → OFF 09:00`, `2차 …` 처럼 쌓이고, 건마다 시간·일당 계산(1~6시간 버튼·직접 입력)·계좌 문자·삭제가 가능합니다.
  - 근무중인 줄의 `시간·거래처`로 지금까지의 시간을 골라 마감하거나 거래처를 붙일 수 있습니다. 잘못 켰을 때는 `삭제`(작게)로 지웁니다.
  - 기준일은 **낮 12시에 리셋**됩니다(00:00~11:59는 전날 출역이 이어짐). 지난 근무 기록은 삭제되지 않고 기록 탭에 남습니다.
- **자주 가는 거래처 추천**: 근무 등록·마감 창에서 그 인력이 과거에 가장 많이 간 거래처를 `⭐ 자주 가는 거래처` 칩으로 상위 노출하고, 거래처 자동완성 목록도 많이 간 순서로 보여 줍니다.
- **인력별 거래처 통계**: 인력 카드에 `자주 가는 곳`(상위 3곳 · 횟수)과 `거래처 통계 N곳` 버튼. 통계 창에서 거래처별 횟수·시간·금액·최근 근무 순위를 봅니다.
- **거래처 직접 입력 자동 등록**: 근무 등록·빠른 등록에서 목록에 없는 거래처명을 입력하면 같은 이름이 있을 때는 그 거래처에, 없으면 새 거래처(`wf_clients`)로 등록해 근무 기록에 연결합니다.
- **연락처 파일 가져오기(.vcf)**: 안드로이드 vCard 2.1 의 `ENCODING=QUOTED-PRINTABLE` UTF-8/EUC-KR 한글을 해독합니다. 이미 `=ED=99=A9...` 형태로 저장된 이름은 앱을 열 때 자동으로 한글로 복구해 DB에도 반영합니다.

- **📒 장부 탭**: 월별(또는 전체) 총 매출(거래처 청구) · 총 인건비(인력 지급) · 일일 지출 · 실제 순수익(매출−인건비−지출) · 미수금 · 미지급.
  - 거래처별 청구/입금/미수금 잔액과 **입금 완료 · 계좌 문자** 바로 실행, 거래처별 **청구 시급**(이 기기 기준) 설정
  - 인력별 근무시간·일당/지급액/미지급 잔액과 **지급 완료** 바로 실행
  - **장부는 직접 적는 수입·지출만** — 자세한 내용은 아래 [장부 — 직접 적는 수입 · 지출](#장부--직접-적는-수입--지출-2026-11-26-변경) 절을 보세요. (미수금·미지급·거래처별/인력별 장부는 장부 탭에서 없어졌고, 입금 처리·계좌 문자는 `근무·입금`·`전체 근무 기록`에 있습니다)
- **계좌 문자 문구**: `날짜 / 인력 시간 · 금액 / 합계 / 입금 계좌`만 담습니다. `[근무 청구]` 머리말과 거래처명은 넣지 않습니다.
- **근무시간 외 수당**: 근무 등록·수정(`+ 근무 등록`, `[시간]`) 창에 **추가 수당(원)** 과 **수당 사유(선택)** 가 있습니다. `1만·2만·3만·5만` 칩으로 바로 넣을 수 있고, **일당 = 근무시간 × 시급 + 수당** 으로 계산합니다. 오늘 출역 목록·일당 합계·계좌 문자·전체 근무 기록에 반영됩니다 (장부에는 넣지 않습니다)(`김철수 3시간 + 수당 20,000원 · 170,000원`).
- **기록은 빈 상태에서 시작**: 앱을 처음 열거나 DB가 비었을 때 샘플 근무·문자·지출을 자동으로 만들지 않습니다. 이전 버전이 이 기기에 남긴 샘플 근무·문자·지출 기록도 한 번 비우고(인력·거래처·관리자는 유지), 지운 DB를 다시 채우지 않습니다.
- **앱 아이콘**: `icon-192.png` · `icon-512.png` · `apple-touch-icon.png` + `manifest.webmanifest`(SH 인력) — 홈 화면에 추가하면 골드 SH 아이콘으로 설치됩니다.
- **뒤로가기(안드로이드)**: 모달이 열려 있으면 그 모달만 닫히고, 탭 화면에서는 직전 탭으로 돌아갑니다.

## 연령대 구분 · 오늘 출역 한눈에 (2026-11-25 추가)
- **연령대 구분 6단계**: `20대` · `생초 (30초~30중)` · `어린생점·어생 (30후~40초)` · `생점 (40중~40후)` · `젊초 (50대)` · `젊은점 (50대후)`.
  - 인력 추가·수정 창에서 용어 버튼으로 고르고, **나이(세)를 넣으면 해당 구간의 용어가 자동으로 선택**됩니다(20~29 20대 · 30~36 생초 · 37~41 어생 · 42~49 생점 · 50~54 젊초 · 55+ 젊은점). 직접 고른 용어는 나이를 고쳐도 유지됩니다.
  - 저장 칸은 `wf_workers.age_group`. **칸이 없어도(SQL 재실행 전) 앱은 그 칸만 빼고 저장**하고, 고른 구분은 이 기기에 남겨 다시 열어도 그대로 보입니다(상단 안내 토스트). 관리자 3명이 같이 보려면 `supabase-schema.sql`을 한 번 더 실행하세요.
  - **인력 탭**: 연령대별 인원 칩(필터) + 인력 카드를 용어별로 묶어 표시, 카드마다 색 배지(`생초` 등)와 `생초 (30초~30중) · 만 33세` 표기. 검색어에 용어를 넣어도 찾아집니다.
- **오늘 출역 한눈에**: 상단에 `전체 인원 / 출근 / ON / OFF` 숫자 보드(누르면 그 인원만 필터), `출근 N명 · ON N · OFF N` 요약.
  - 명단은 **출역 중(ON) → 출근·마감(OFF) → 미출역(OFF)** 순으로 묶여 보이고, 각 인력 이름 옆에 연령대 배지가 붙습니다. 연령대 칩으로 명단을 좁힐 수 있습니다.

## 출근 버튼 (2026-11-25 추가)
- **오늘 출역 명단의 인력마다 `출근` 버튼**: 누르면 파란 `✓ 출근 완료`로 바뀌고, 다시 누르면 해제됩니다. ON/OFF(실제 근무 시간)와 따로, **오늘 왔는지**만 남깁니다.
  - 출근한 줄에는 `출근 완료 07:52 · 출근: 관리자 1` 처럼 **누른 시각과 누른 관리자**가 함께 보입니다.
  - `출근`을 안 누른 채 `ON`을 누르면 **출근도 자동으로 체크**됩니다. 이미 출근한 인력이 ON을 눌러도 처음 누른 출근 시각은 그대로입니다.
  - ON(근무중)인 동안에는 출근을 해제할 수 없습니다(OFF 후 해제).
  - 기준일은 오늘 출역과 같이 **낮 12시에 바뀌므로**, 12시가 지나면 어제 출근은 오늘 출근으로 세지 않습니다.
- **요약 보드 `출근` 칸과 필터**가 이 버튼 상태와 그대로 연동됩니다(`전체 인원 10 · 출근 7 · ON 5 · OFF 5`).
- 저장: `wf_workers.attend_day`(출근한 기준일) · `attend_at`(누른 시각 ISO) · `attend_by`(누른 관리자 id). 관리자 3명 기기에 **실시간으로 함께 반영**됩니다. 칸이 없어도 앱은 그 칸만 빼고 저장하고 출근 상태는 이 기기에 남깁니다.

## 전체 근무 기록 (2026-11-26 추가)
- **오늘 출역 카드의 `📋 전체 근무 기록` 버튼**: 누르면 **모든 인력의 오늘·지난 근무 회차**가 한 창에 모여 나옵니다(오늘 회차가 맨 위, 지난 기록은 날짜별 묶음). 오늘 출역 명단에서 숨겨진 마감 회차와 다른 관리자가 넣은 기록도 모두 보입니다.
  - **창 맨 위 오늘 인력별 근무 시간 (2026-11-27 추가)**: `⏱ 오늘 근무 시간 11/26(목)` 아래에 `강이 7시간` · `정원 5시간`처럼 **인력별 오늘 근무 시간 합계**를 칩으로 한눈에 보여 줍니다(시간이 많은 순). 30분 단위는 `5시간 30분`, 오늘 기록이 없으면 `오늘 근무 기록 없음`으로 나옵니다. 아직 **근무중(ON)** 인 인력은 마감된 시간 옆에 `근무중 25분`(경과)이 붙고, 아래 `오늘 … · N시간` 합계와 같은 셈이 되도록 마감된 회차만 합산합니다.
  - 회차마다 **인력 이름 · 날짜 · 시작~종료 시간 · 근무시간 · 거래처 · 일당(수당 포함 표시) · 입금 상태**(`거래처 입금완료/미입금 · 인력 지급완료/미지급`)가 한 줄에 보이고, 근무중(ON) 회차는 `근무중`으로 표시됩니다.
  - 창 위 요약: `전체 기록 N건` · `오늘 회차 N건` · `받을 돈`(거래처 미입금 합계) · `줄 돈`(인력 미지급 합계).
  - 회차마다 **계좌 문자 · 수정 · 삭제** 바로 실행(근무중 회차는 `마감·거래처`).
  - 맨 위 **`＋ 새 근무시간 등록`** → 기존 빠른 등록 창이 열리고, **등록·수정·삭제를 마치면 이 전체 근무 기록 창으로 돌아옵니다**(취소하면 돌아오지 않습니다).
  - 아래 **`근무·입금 탭에서 보기`** → 인력·상태 필터를 전체로 풀고 근무·입금 탭으로 이동합니다.
- 오늘 출역 카드의 버튼은 `📋 전체 근무 기록` 하나입니다(예전 `오늘 근무시간 등록` 버튼은 없앴습니다). 직접 등록은 `근무·입금` 탭의 `+ 근무 등록`과 이 창의 `＋ 새 근무시간 등록`에서 합니다.
- 조회 전용 화면이 아니라서 창을 닫지 않고 바로 고칠 수 있습니다(뒤로가기로 창만 닫힘).

## 장부 — 직접 적는 수입 · 지출 (2026-11-26 변경)
- **장부 탭은 100% 수동 입력입니다.** 출역(`wf_logs`)에서 매출·인건비·근무수당을 끌어오지 **않습니다**. 장부에 보이는 숫자는 관리자가 장부 탭에서 직접 적은 **수입**과 **지출**뿐입니다.
- **요약**: 고른 기간(이번 달 / 월별 / 전체)의 **💵 총 수입 · 🧾 총 지출 · 📒 순수익(수입 − 지출)**. 미수금·미지급·거래처별 장부·인력별 장부는 장부 탭에서 없앴습니다(입금 처리·계좌 문자는 `근무·입금` 탭과 `전체 근무 기록` 창에 그대로 있습니다).
- **＋ 수입 / ＋ 지출** 버튼 → 구분(수입/지출)·날짜·분류·금액·내용을 적어 등록합니다. 구분을 바꾸면 분류 목록도 바뀝니다(수입: 현장/용역/기타, 지출: 식대·유류비·교통비·자재비·기타).
- **내역은 장부 탭을 누르면 바로** 날짜별로 펼쳐 보입니다(수입 `+금액` 파란 배지 / 지출 `−금액` 빨간 배지, 행마다 `수정`·`삭제`). 위 **전체/수입/지출** 칩으로 걸러 봅니다.
- DB: `wf_expenses` 에 `kind`(`income`/`expense`, 기본 `expense`) 칸을 씁니다. 예전 기록(kind 없음)은 지출로 봅니다. 칸이 없는 DB에서도 앱은 그 칸만 빼고 저장합니다(실행: `alter table public.wf_expenses add column if not exists kind text default 'expense';`).

## 화면 다시 그리기 · 스크롤 유지 (2026-11-26 수정)
- **다른 관리자가 자료를 만져도(실시간 DELETE·UPDATE) 내 화면이 맨 위로 튀지 않습니다.** 내가 삭제·출근 토글·필터를 눌러 다시 그릴 때도 보던 자리를 지킵니다. 탭을 옮길 때만 맨 위로 갑니다.
- 고친 것: ① 연속으로 두 번 다시 그려도(`render()` 경합) 처음 보던 자리를 계속 씀 · ② 창 뿐 아니라 문서·`body`·`#view` 등 **실제 스크롤되는 상자**를 모두 함께 되돌림 · ③ 내용을 갈아 끼우는 동안 `min-height` 로 높이를 잠깐 고정해 지운 줄 때문에 스크롤이 위로 눌리는 것을 막음 · ④ 다음 프레임·90ms·260ms에 한 번씩 더 맞춤(사진·글꼴·주소창 높이 변화) · ⑤ 창을 닫아 body 스크롤 잠금이 풀릴 때 맨 위로 가는 기기 대응 · ⑥ 되돌리는 중에 사용자가 직접 스크롤하면 붙들지 않음.
- **새 화면이 바로 반영되게**: 서비스 워커 캐시 이름을 `sh-wf-v2` 로 올리고 화면 요청은 `cache: 'no-store'` 로 받습니다(`skipWaiting` + `clients.claim`). 설정 창 아래 **화면 버전**에서 휴대폰이 새 화면을 받았는지 확인할 수 있습니다.

## 최초 1회 설정
1. Supabase 대시보드 → SQL Editor 에서 `supabase-schema.sql` 전체를 실행합니다.
2. 앱을 열면 상단 칩이 `🟢 실시간 연결됨`으로 바뀝니다. (DB가 비어 있으면 빈 상태로 시작하며, 샘플 데이터를 자동으로 만들지 않습니다.)
3. 앱을 열면 로그인 화면이 뜹니다. 관리자를 고르고 초기 비밀번호 `1234`로 들어간 뒤, 설정에서 관리자별 이름과 비밀번호를 바꿔 주세요. 이후 기록·문자·메신저에 그 관리자 이름이 남습니다.
4. 이미 쓰고 있던 DB라면 `supabase-schema.sql`을 한 번 더 실행하세요. `wf_logs` 에 `on_at`·`off_at`·`allowance`·`allowance_memo`·`updated_by`·`updated_at`, `wf_expenses` 에 `updated_by`·`kind`(수입/지출), `wf_workers` 에 `age_group`(연령대 구분)과 `attend_day`·`attend_at`·`attend_by`(출근 버튼) 칸이 추가되고 `wf_admins`(관리자 계정) 표가 생깁니다(칸이 없어도 앱은 그 칸만 빼고 저장합니다 — 관리자 3명이 같은 비밀번호·연령대 구분·출근 상태를 함께 쓰려면 꼭 실행하세요).

## 참고
- 브라우저에는 publishable(anon) 키만 들어 있습니다. `sb_secret_...` 키는 절대 넣지 않습니다.
- 공개 데모용 설정(RLS + anon 허용 정책)이므로 실제 개인정보·민감정보는 넣지 마세요.
